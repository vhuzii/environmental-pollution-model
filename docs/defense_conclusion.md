# Висновок для захисту першого етапу

**Тема:** Моделювання поширення атмосферного забруднення та оцінювання економічної ефективності заходів зі зменшення викидів

**Тип даних:** синтетичні (synthetic / illustrative). Реальне підприємство, офіційні ГДК і затверджена грошова методика на цьому етапі не використовуються; за потреби їх можна підставити пізніше без зміни структури моделі.

---

## 1. Що зроблено на першому етапі

1. Обрано тему економіко-екологічного проєкту.
2. Сформульовано постановку задачі, об’єкт і предмет дослідження.
3. Визначено екологічні та економічні показники.
4. Зафіксовано доступні джерела даних і перелік даних, яких поки немає.
5. Підготовлено модульну програму з розрахунком гаусового шлейфу, порівнянням сценаріїв і інтерфейсом Streamlit.

**Об’єкт дослідження** — територія навколо одного стаціонарного точкового джерела атмосферних викидів.

**Предмет дослідження** — закономірності поширення забруднювальної речовини та навчальні економічні наслідки скорочення викидів.

## 3. Метод розрахунку (коротко)

Приземна концентрація постійного точкового джерела:

```text
C(x, y, 0) = Q / (2 π u σy σz)
           × exp(-y² / (2 σy²))
           × 2 × exp(-H² / (2 σz²))
```

Далі: переведення г/м³ → мкг/м³ (`× 1 000 000`), додавання фону, порівняння з порогом C_lim.

Навчальний збиток по комірках із перевищенням:

```text
N_i = ρ × A_i
D_i = k_d × N_i × T × (C_i − C_lim) / C_lim
D = Σ D_i
```

Вартість заходу і чистий ефект:

```text
Q(p) = Q × (1 − p/100)
C_mit(p) = (p/100) × (C_inst + C_op)
avoided_damage = D(0) − D(p)
net_effect = avoided_damage − C_mit(p)
```

σy, σz — сільські формули Бріггса для класу D. Деталі: `docs/mathematical_model.md`.

## 4. Результати екологічного розрахунку (базовий сценарій, p = 0%)

| Показник | Значення |
| --- | ---: |
| Максимальна приземна концентрація | **117,85 мкг/м³** |
| Середня концентрація по сітці | 6,48 мкг/м³ |
| Точка максимуму відносно джерела | схід 1 600 м, північ 0 м |
| Відстань максимуму за вітром | 1 600 м |
| Поріг C_lim | 50 мкг/м³ |
| Перевищення максимуму над порогом | 117,85 / 50 ≈ **2,36 раза** |
| Площа зони перевищення | **1,31 км²** |
| Частка розрахункової території | **1,60%** |

Інтерпретація простими словами: за синтетичними умовами шлейф SO₂ формує вузьку зону перевищення навчального порога на схід від джерела. Максимум — близько 1,6 км за вітром. Більша частина території (≈ 98,4%) залишається нижче порога; середнє по сітці близьке до фону, бо територія велика.

Числа округлені для захисту; повні значення відтворюються командою `streamlit run app.py` або модулем `analyze()` на `DEFAULT_INPUTS`.

### Екологічний висновок за сценаріями

- Скорочення на **30%** зменшує максимум до ≈ 84 мкг/м³ і площу перевищення майже вдвічі.
- Скорочення на **60%** майже знімає перевищення порога (площа 0,02 км²; максимум ≈ 50,1 мкг/м³ — ледь вище порога).
- Скорочення на **90%** повністю усуває зону перевищення навчального порога (максимум ≈ 16,3 мкг/м³ < 50).

### Економічний висновок (навчальні коефіцієнти)

За обраними синтетичними грошовими ставками **жоден захід очищення не дає додатного чистого ефекту**: уникнений збиток (до ≈ 94 тис. грн) менший за вартість заходу (від 261 тис. до 783 тис. грн).

Це **не** означає, що очищення «не потрібне» в реальності. Це означає, що при поточних навчальних k_d, T і вартостях очищення грошова модель показує від’ємний баланс. Якщо викладач попросить доробити — підставляємо реальні ставки збитку / ГДК / параметри джерела; структура розрахунку вже готова.

## 6. Головний висновок для захисту

На першому етапі побудовано робочу модульну програму, яка:

1. рахує поле приземної концентрації від одного точкового джерела;
2. виділяє зону перевищення заданого рівня і оцінює наближене населення;
3. порівнює щонайменше чотири сценарії скорочення викидів;
4. показує результати на карті, профілі шлейфу та в таблиці.

**За синтетичним базовим розрахунком:** максимум SO₂ ≈ **118 мкг/м³** на відстані **1,6 км** за вітром; зона перевищення порога 50 мкг/м³ — **1,31 км²** (≈ **524** особи за рівномірною густотою). Зменшення викидів на 60–90% екологічно ефективно знімає або майже знімає перевищення, але за навчальними грошовими коефіцієнтами чистий економічний ефект від’ємний — тобто для подальших етапів варто уточнити економічні ставки, а не фізичне ядро моделі.

Обмеження першої версії: одне джерело, рівна місцевість, сталий вітер, навчальний поріг і навчальні грн; OpenAQ не калібрує модель. Повний перелік — у `docs/assumptions_and_limitations.md`.
