# Математична та економічна моделі

Це навчальне спрощення. Воно не є промисловою моделлю розсіювання і не відтворює ОНД-86, AERMOD або CALPUFF.

## Система координат

Джерело стоїть у початку координат. Вісь на схід і вісь на північ задані в метрах. Напрямок вітру — метеорологічний: звідки дме вітер, градуси від півночі за годинниковою стрілкою.

Нехай θ — цей кут у радіанах, E — координата на схід, N — координата на північ. Відстань за вітром і поперечна відстань:

```text
x = -E sin θ - N cos θ
y =  E cos θ - N sin θ
```

Якщо x ≤ 0, повітря в цій точці не проходило повз джерело. Внесок шлейфу там дорівнює нулю, а показана концентрація дорівнює фону.

## Приземна концентрація

Для постійного точкового джерела:

```text
C(x, y, z) = Q / (2 π u σy σz)
           × exp(-y² / (2 σy²))
           × [exp(-(z - H)² / (2 σz²)) + exp(-(z + H)² / (2 σz²))]
```

На поверхні землі z = 0, тому обидва вертикальні доданки однакові. Другий доданок є повним відбиттям від землі. Окремого потоку сухого осадження в цій формулі немає.

Одиниці у формулі:

| Позначення | Величина | Одиниця |
| --- | --- | --- |
| Q | інтенсивність викиду | г/с |
| u | швидкість вітру | м/с |
| H | ефективна висота | м |
| x, y, z | координати шлейфу | м |
| σy, σz | коефіцієнти розсіювання | м |
| C | концентрація до переведення | г/м³ |

Переведення:

```text
C [мкг/м³] = C [г/м³] × 1 000 000
```

оскільки 1 г = 1 000 000 мкг. Після переведення додається фонова концентрація, також у мкг/м³:

```text
C_total = C_plume + C_background
```

Швидкість вітру має бути додатною. При u = 0 формула ділить на нуль і фізично не описує штиль, тому розрахунок зупиняється з поясненням.

## Природний розпад

```text
C_decay = C × exp(-k x / u)
```

Тут k має одиницю 1/с, а x / u — секунди шляху повітря. При k = 0 множник дорівнює одиниці. Це не модель хімічної трансформації суміші речовин.

## Коефіцієнти розсіювання

Якщо користувач не задав сталі σy і σz, вони залежать від відстані x і класу стійкості Паскуіла. Використано сільський запис Бріггса, x у метрах.

Горизонтальне розсіювання:

```text
σy = a x / sqrt(1 + 0.0001 x)
```

| Клас | a |
| --- | --- |
| A | 0.22 |
| B | 0.16 |
| C | 0.11 |
| D | 0.08 |
| E | 0.06 |
| F | 0.04 |

Вертикальне розсіювання:

| Клас | σz |
| --- | --- |
| A | 0.20 x |
| B | 0.12 x |
| C | 0.08 x / sqrt(1 + 0.0002 x) |
| D | 0.06 x / sqrt(1 + 0.0015 x) |
| E | 0.03 x / (1 + 0.0003 x) |
| F | 0.016 x / (1 + 0.0003 x) |

Щоб не ділити на нуль у самому джерелі, для розрахунку σ відстань, меншу за 1 м, замінюють на 1 м. Сам розпад і далі використовує справжнє x. Біля джерела гаусова формула все одно ненадійна.

Сталі σy і σz є ще сильнішим спрощенням: вони не ростуть із відстанню.

## Екологічні зведення

Максимум і його координати беруться по вузлах сітки. Середнє — це середнє всіх вузлів, включно з фоном, тому воно зменшується, якщо розширити територію, не змінюючи шлейф.

Комірка входить до зони перевищення, коли `C_total > C_lim`. Площа зони — число таких комірок, помножене на квадрат кроку. Частка — це відношення площі зони до площі всієї сітки.

```text
exposed_population = polluted_area_km2 × population_density
```

## Економічна формула

Для кожної комірки з перевищенням:

```text
N_i = ρ × A_i
D_i = k_d × N_i × T × (C_i - C_lim) / C_lim
D = Σ D_i
```

| Позначення | Зміст | Одиниця |
| --- | --- | --- |
| ρ | густота населення | осіб/км² |
| A_i | площа комірки | км² |
| T | тривалість впливу | год |
| k_d | навчальний коефіцієнт збитку | грн / (особа · год · одиниця відносного перевищення) |
| D | навчальний збиток | грн |

Вартість заходу задають для повного, стовідсоткового скорочення викиду. Для сценарію зі скороченням на p відсотків прийнято лінійне припущення:

```text
C_mit(p) = (p / 100) × (C_inst + C_op)
```

`C_inst` — вартість встановлення, грн. `C_op` — експлуатаційні витрати за період аналізу, грн, а не ставка за годину. Для базового сценарію p = 0 вартість дорівнює нулю.

Інтенсивність викиду сценарію:

```text
Q(p) = Q × (1 - p / 100)
```

Зменшення збитку і чистий ефект рахують відносно базового сценарію:

```text
avoided_damage = D(0) - D(p)
net_effect = avoided_damage - C_mit(p)
```

Додатний чистий ефект у цій формулі означає лише те, що навчальне зменшення збитку перевищило навчальну вартість заходу. Це не висновок офіційного вартісного аналізу.

Порівнюються щонайменше чотири сценарії: 0%, 30%, 60% і 90%. Якщо на карті вибрано інший відсоток, він додається окремим рядком.
